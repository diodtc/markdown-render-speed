A fast, dependency-free Markdown parser for Node 22 that renders exactly the HTML marked 18.1.3 produces with default options (GFM on, breaks off), byte for byte — but faster. The grammar regular expressions come from marked 18.1.3 (MIT, see LICENCE); the lexer, parser and renderer are original work.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
